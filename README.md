# OilMaster: Soluciones Tecnológicas para la Industria Petrolera

## Descripción
OilMaster es una plataforma integral de aplicaciones web que proporciona herramientas avanzadas para la industria petrolera, cumpliendo con los más altos estándares internacionales y mejores prácticas del sector.

## Características Principales

### 1. Oil-IPR-VFP
- Análisis de curvas IPR-VFP según estándares API/SPE
- Predicción de flujo natural y levantamiento artificial
- Optimización de tubería basada en API RP 14E
- Cumple con API RP 11V6 para análisis nodal

### 2. SOTE Simulator
- Simulación de oleoductos según ASME B31.4
- Monitoreo en tiempo real bajo ISO 31000
- Gestión de riesgos según API 1173
- Parámetros críticos validados por API MPMS

### 3. Mechero Simulator
- Cumple con regulaciones EPA para emisiones
- Modelado según API 521 para sistemas de alivio
- Estándares de seguridad API RP 521/520
- Análisis ambiental según World Bank Standards

### 4. SIMREF-HC 2025
- Estándares API/ASTM para calidad de productos
- Modelado económico según IAS/IFRS
- Optimización según API RP 557
- Benchmarking con estándares Solomon Associates

### 5. Simulador de Generación Eléctrica
- Cumple con IEEE 1547 para interconexión
- Estándares API para manejo de gas
- ISO 50001 para gestión energética
- Normas IEC para equipos eléctricos

### 6. WTI-OIL Precio del Petróleo
- Datos validados por U.S. EIA
- Estándares IPE/ICE para mercados
- Cumplimiento API/OPEP para reportes
- ISO 8601 para series temporales
